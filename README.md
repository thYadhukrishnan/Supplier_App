# Supplier_App

Laravel 11,
Excel - maatwebsite/excel: "3.1.58",
PDF   - barryvdh/laravel-dompdf: "^3.0",

Description 

The landing page will be Product Order Details, where you can navigate to Supplier and Item Modules. From Supplier and Item Modules, you can add supplier and item. The item list page also has the buy option. The bought product details will be shown in the product order details page.
